# Todo

優先度を4分類して整理する、iPhone向けのローカルファーストTodoアプリ。Expo SDK 58 / React Native / TypeScriptで実装しています。

## 起動

Node.js 24、Xcode、CocoaPodsが必要です。ウィジェットはExpo Goでは動かないため、iOS開発ビルドを使います。

```sh
nvm use
npm ci
npm run ios
```

最初にアプリを開いてから、ホーム画面のウィジェット追加で「Todo」を選んでください。ロック画面の追加はロック画面のカスタマイズから行います。実機ではApple Developerの署名とApp Groupの利用設定が必要です。

画面・保存操作のWebプレビューは `npm run web` で開けます。WebにはiOSウィジェットはありません。

## 実装内容

- ひとつの未完了一覧を「緊急かつ重要」「重要だが緊急ではない」「緊急だが重要ではない」「緊急でも重要でもない」の見出しと細い区切り線で分類。空の分類も見出し・件数・追加ボタンだけで表示。
- 分類内は期限日時の昇順、期限なしは最後。同じ期限・期限なし同士は手動順を維持。上下ボタンで並べ替え。
- タスクの追加・編集・削除・完了・未完了への復元、期限日時とメモの編集。
- 端末内にタスク・設定・下書きを保存。編集中の終了時は下書き保存・破棄・継続を選択。別の下書きの上書きは確認してから実施。
- 保存処理は1つの文書に対する直列書き込み。保存に失敗した変更は確定せず、破損した保存データも勝手に初期化しません。
- オフホワイトを初期配色にし、設定から「オフホワイト」「ダーク」「端末に合わせる」を選択。配色は端末内に保存し、既存データに配色設定がなければオフホワイトで開く。ステータスバー・日時入力も配色に追従。
- 標準の文字サイズ拡大、操作ラベル、分類名による色以外の識別。完了一覧にも元の分類名を表示。

## ウィジェット

`expo-widgets`でApp Group、WidgetKit拡張、タイムラインの永続化と更新を設定しています。アプリのReact状態・Hooks・Contextはウィジェットから参照しません。アプリから渡す表示用データにメモは含みません。

ホーム画面は小・中・大に対応。共通ロジックで並べた未完了タスクを表示し、タイトルは最大2行、分類ラベルと期限を添えます。SwiftUIの実際の領域とDynamic Typeに対応したフォントの計測から、残件数欄も含めて収まる最長のタスク列を選びます。件数はサイズ別の固定値にしていません。残りは「ほかにあと○件」で表示します。

公開されているExpo UIのウィジェットAPIには領域・文字高の計測機能がないため、ホーム画面の描画をSwiftUIで補完しています。iOS 17以降はロック画面もSwiftUIで描画し、App Intentの完了ボタンを使います。`plugins/with-adaptive-todo-widget.js`がprebuild時に、Expoの生成したファイルへアプリ所有のSwiftUIコードを組み込みます。Expo本体やnode_modulesを変更するパッチはありません。プラグインは実行順の都合で `app.json` の `expo-widgets` より前に記載してください。生成テンプレートが変わった場合は黙って適用せずエラーにします。

ロック画面はインライン・円形・長方形に対応。「今日」は端末の現地日付で、期限日が今日の未完了タスクです。「次」は分類をまたいで期限が最も近い未完了タスク（期限超過も含む）。期限のあるタスクがなければ4分類の並び順で選びます。

ロック画面の表示枠はiOSが決める3形式です。横長は左に今日の件数、細い区切りを挟んで右に次のタスク名（最大2行）と期限を置きます。件数のみ・次のタスクのみの場合は空いた幅を使います。円形はOSのAccessoryWidgetBackgroundに件数を大きく表示し、次のタスクのみなら矢印と短いタスク名を表示します。時計上の1行型はチェックリストの記号と短い要約です。固定の白・黒や分類色に頼らず、OSの前景色と階層表現を使います。0件とタスクなしは区別し、数字は等幅、1000件以上は小さな枠では「999+」（VoiceOverには正確な件数）にします。両方オフならTodoの表示だけを残します。

次のタスクの期限表示も日付切替で更新するため、件数の表示をオフにしていてもタイムラインを予約します。次タスクをオフにした場合は、タスク名に加えて期限・空状態の情報も共有データから除外します。

`node scripts/preview-lock-widgets.cjs` はiOS 16向けのExpo描画の確認用です。iOS 17以降の対話型ロック画面は `plugins/native/TodoInteractiveLock.swift` で描画するため、このHTMLでは確認できません。実機の文字サイズ・壁紙に対する視認性は別途確認が必要です。

ロック画面の件数と次タスクは設定で独立に切り替えられ、オフの情報はロック画面用データからも除きます。長方形・インラインでは両方、円形では件数を優先して表示。両方オフでは「Todo」のみを表示します。期限日とその翌日の現地午前0時に切り替わるタイムラインを予約します。タイムゾーン変更後はアプリを開くと作り直します。

追加・編集・完了・復元・削除・並べ替え・設定変更後とアプリの再開時に更新します。iOSが更新タイミングを制御するため、ホーム画面への即時反映は保証されません。

iOS 17以降ではホーム画面の小・中・大のタスク行を押すと、その場で完了します。ロック画面の長方形の次タスク欄と、件数を非表示にした円形のタスク名でも完了できます。件数欄や背景は一覧を開きます。横一行のロック画面ウィジェットとiOS 16はOSが対話ボタンに対応しないため、タップで一覧を開きます。

ホーム画面ウィジェットにも配色設定を渡し、SwiftUI側にオフホワイト・ダーク・端末に合わせる描画を実装しています。この描画変更をインストール済みのウィジェットに反映するにはprebuildとiOSアプリの再ビルドが必要です。ロック画面はiOSの描画に従います。

完了操作はApp Group内の専用ディレクトリに操作ごとのJSONとして原子的に保存し、アプリが終了中でも残ります。ウィジェットは未反映の完了操作を表示から除外して更新し、該当タスクの通知予約を取り消します。アプリは起動・再開・保存時とフォアグラウンド中に操作を取り込み、AsyncStorageへの保存成功後に受領済みの操作ファイルを削除します。保存した操作IDで重複取り込みを防ぎ、アプリで未完了に戻した後に古い操作が再適用されないようにします。操作ファイルにはタスク名・メモを含めません。`modules/todo-widget-actions` のネイティブモジュールを追加したため、利用にはアプリの再ビルドが必要です。

### リマインダー

タスク編集の「リマインダー」で期限とは独立した通知日時を複数指定できます。「通知日時を追加」で増やし、各日時を変更・削除できます。それぞれの日時にiPhone上のローカル通知を1回予約します。通知を設定したタスクの保存時にだけ通知許可を求めます。拒否された場合は入力内容を残し、iPhoneの設定で通知を許可するか、リマインダーをオフにして保存できます。

「繰り返し通知」では毎日・平日・任意の曜日と時刻を指定できます（初期値は毎日8:00）。単発の通知日時と併用でき、iOSのカレンダー通知でアプリ終了中も端末の現地時刻に繰り返します。完了・削除・設定解除で停止し、未完了へ戻すと再予約します。タスク自体を毎日自動で未完了に戻す機能ではありません。毎日は1件、曜日指定は選んだ曜日ごとに1件の予約を使用し、単発通知と合計60件までです。

期限日時を設定すると、「10分前」「30分前」「1時間前」のボタンで通知日時を追加できます。設定済みの通知は上書きせず、同じ日時は重複させません。過去になる通知日時は設定せず、案内を表示します。期限日時を後から変更しても、追加済みの通知日時は維持します。通知を変更したい場合は各日時を変更・削除してください。

完了・削除・リマインダー解除時には予約を取り消し、タスク名・日時変更時には予約を更新します。未完了に戻した場合は未来の日時に限って再予約し、過去の通知を即時発火させません。起動・フォアグラウンド復帰時にも保存データとOSの予約を照合し、失敗した場合は一覧に再試行の案内を表示します。通知タップで該当タスクを開きます。通知にメモは含めません。

通知予約は単発・繰り返しを合わせて全タスク合計60件までです。ブラウザー版では日時の編集はできますが通知の受信はできません。保存形式は従来の `reminderAt` を読み込め、編集保存すると `reminderAts` 配列に引き継ぎます。空の配列は通知解除を表し、古い通知を復活させません。日時を変更しなければ、過去の通知日時が残ったタスクも編集できます。通知の表示・音はiOSの通知設定や集中モードに従います。

`expo-notifications`（SDK 58互換）と完了連携モジュールを含む、**更新版アプリのビルド・インストールが必要です**。2026-11-09にiOS Simulator向けビルドは成功しました。実機では複数日時の通知、完了・削除による全予約の取消、通知タップ、許可拒否からの復帰、アプリ終了中のウィジェット完了と再開時の反映を確認してください。

公式資料: [Expo SDK 58 Widgets](https://docs.expo.dev/versions/v58.0.0/sdk/widgets/)、[Expo Router 58の変更点](https://docs.expo.dev/router/migrate/sdk-57-to-58/)。

2026-11-09の繰り返し通知追加では、毎日・曜日指定の予約更新／取消、保存データ検証、単発通知との併用をテストしました。ブラウザー操作で初期時刻8:00、平日から任意曜日への変更、時刻変更、再読み込み、個別解除、320px幅の表示を確認しています。実機での繰り返し通知の着信確認は未実施です。

### テーマカラー

設定の「テーマカラー」からグリーン・ブルー・ラベンダー・ローズ・オレンジ・グレーを選べます。アプリ内の主要ボタン、完了チェック、通知などのスイッチに反映し、オフホワイト／ダーク／端末に合わせる設定と併用できます。背景やタスクの4分類の意味を示す色は維持します。色は端末に保存し、従来データはグリーンで表示します。ウィジェットの配色は従来の明暗設定に従います。
